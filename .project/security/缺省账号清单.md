# auto_performance 缺省账号清单

**产品**：auto_performance（性能测试平台）　**版本**：v1.0　**日期**：2026-10-26
**目的**：满足 DES-S-003 / TEST-S-003「无未文档化账号、无隐藏口令」——本清单是产品内**全部**内置账号与口令来源的唯一说明。
*本文件含初始凭据，属内部资料：不得外发，交付后由部署方立即执行 §5 的改密动作。*

---

## 1. 应用账号

### 1.1 内置管理员（唯一内置应用账号）

| 项 | 值 |
|----|----|
| 登录名 | `admin` |
| 显示名 | 内置管理员 |
| 初始口令 | `Cqmyg@123` |
| 口令存储 | bcrypt（cost=10，`$2a$10$…`），不存明文；源码与二进制中不含明文口令 |
| 首次登录 | **强制修改口令**（`must_change_password=true`）：修改前仅可访问 `/auth/change-password`、`/auth/logout`、`/auth/me` |
| 权限 | `is_builtin=true` → 隐式拥有全部子模块权限（不依赖角色表） |
| 状态 | `enabled`；**不可删除、不可停用**（返回业务码 `26002`） |
| 手机号/邮箱 | 空（不预置个人数据） |

> 初始口令仅通过本文件下发；迁移 SQL 只保存哈希，且迁移文件随 `go:embed` 进入二进制，
> 因此已移除其中任何明文口令（`strings <bin> | grep -i 'Cqmyg'` 无命中，见《安全专项测试证据》）。

### 1.2 其他应用账号

**无**。产品不预置演示账号、测试账号、运维后门账号。

通过「系统设置 → 管理员管理」新建的账号遵循：

| 项 | 新建默认值 |
|----|-----------|
| 状态 | `enabled` |
| 角色/权限 | **空**（默认无任何权限，需管理员显式绑定角色） |
| 首次登录改密 | `must_change_password=false`（由创建者设置初始口令，建议要求对方自行修改） |
| 可提权字段 | 请求体中的 `role`/`role_ids`/`status`/`is_builtin`/`is_super` 等字段**被忽略**（防 Mass Assignment，DES-E-002） |

## 2. 数据库账号

| 项 | 值 |
|----|----|
| 账号 | `autoperf`（离线安装脚本的 `SERVICE_USER`；容器形态由 `AUTO_PERF_DATABASE_USER` 指定） |
| 权限 | `LOGIN`、`NOSUPERUSER`、`NOCREATEDB`、`NOCREATEROLE`、`NOREPLICATION`、`NOBYPASSRLS`；为数据库 owner |
| 口令 | 安装时由 `--db-password` 指定，或随机生成 16 字节 hex；写入 `config.yaml`（0640） |
| 访问范围 | 仅本机（`listen_addresses=127.0.0.1` + Unix socket）；容器形态不发布 5432 |
| 额外限制 | `REVOKE CREATE ON SCHEMA public FROM PUBLIC`、`REVOKE ALL ON DATABASE … FROM PUBLIC` |

> 随包 PostgreSQL 的超级用户 `postgres` 仅由安装脚本本地调用（`runuser`/peer 认证），不设置口令供远程登录。
> **不要**把应用配置改为使用 `postgres` 超级用户。

## 3. 操作系统账号

| 形态 | 账号 | 说明 |
|------|------|------|
| 离线单机 | `autoperf` | systemd 服务账号（`User=autoperf`），拥有 `/var/lib/auto_performance` 与 KEK；建议设置 `nologin` |
| 容器 | `autoperf`（UID/GID 10001） | 镜像内创建，`USER 10001:10001`，无 root |
| 低权限执行账号（可选） | 由运维创建（如 `autoperf-exec`） | 供 k6 子进程使用（`cleaner.low_priv_uid/gid`），建议无登录 shell |

## 4. 密钥/凭据存放位置

| 凭据 | 位置 | 权限 | 生成方式 |
|------|------|------|----------|
| 内置 admin 初始口令 | 本文件 + 迁移预置哈希 | 内部资料 | 人工预置（仅哈希入库） |
| JWT 签名密钥 | `config.yaml#jwt.secret` 或 `AUTO_PERF_JWT_SECRET` | 0640 | 安装时 32 字节随机 hex |
| 审计链 HMAC 密钥 | `config.yaml#security.audit_hmac_key` 或 `AUTO_PERF_SECURITY_AUDIT_HMAC_KEY` | 0640 / 环境变量 | 安装脚本生成 |
| KEK（信封根密钥） | `data/keys/kek.key` | **0600**（目录 0700） | 安装时 32 字节随机 |
| 应用附加秘密 | `data/keys/secret.env` → `AUTO_PERF_SECRET_KEY` | 0600 | 安装脚本生成 |
| 数据库口令 | `config.yaml#database.password` / `AUTO_PERF_DATABASE_PASSWORD` | 0640 / 环境变量 | 指定或随机 |

## 5. 部署后必须执行

1. **立即登录并修改内置 admin 口令**（满足口令复杂度：≥8 位、含大小写+数字+特殊字符）。
2. 为本产品创建专用运维角色与账号，**不要共用 `admin`**；日常操作使用最小权限账号。
3. 核对账号清单（下）与预期一致；发现任何未登记账号立即停用并排查。
4. 确认 `config.yaml` 中不存在示例默认值（`auto_performance-dev-secret-change-me`、`postgres` 口令）。

### 账号核查

```sql
-- 应用层账号（应只有 admin + 运维自建账号）
SELECT id, username, name, status, is_builtin, must_change_password, created_at
FROM admin WHERE deleted_at IS NULL ORDER BY id;

-- 口令哈希形态（应为 bcrypt $2a$10$，非明文/MD5）
SELECT username, left(password_hash, 7) AS hash_prefix, length(password_hash) AS hash_len
FROM admin WHERE deleted_at IS NULL;

-- 数据库账号权限（不得出现 rolsuper=true）
SELECT rolname, rolsuper, rolcreaterole, rolcreatedb, rolcanlogin
FROM pg_roles WHERE rolname NOT LIKE 'pg\_%';
```

```bash
# 二进制中不得出现明文初始口令/私钥块
strings /opt/auto_performance/bin/auto_performance | grep -iE 'Cqmyg|BEGIN .*PRIVATE KEY'   # 期望无输出
```

## 6. 账号生命周期

| 场景 | 处理方式 |
|------|----------|
| 人员离任/角色变更 | 停用账号（`PATCH /admins/{id}/status`）+ 解绑角色；停用后登录返回 `10202` |
| 口令疑似泄露 | 管理员重置口令（`POST /admins/{id}/reset-password`，强制下次登录改密）或用户自行改密；旧 token 立即失效 |
| 误建账号 | 逻辑删除（`DELETE /admins/{id}`）；内置 admin 不可删除 |
| 权限回收 | 重新绑定角色（全量替换，权限即时生效） |
