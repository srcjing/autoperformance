## 6. 残留风险与结论

| 风险 | 说明 | 处置 |
|------|------|------|
| R-1 | 离线安装默认 `server.host: 0.0.0.0`，端口收敛依赖部署侧（§4-3/4-4 未执行） | 按《安全加固指南》§3 收敛为回环 + 反代 |
| R-2 | 登录锁定为进程内状态，多副本不共享 | 单实例部署或引入共享存储/反代限流 |
| R-3 | `config.example.yaml` 含开发默认 JWT secret（二进制内可见） | 安装脚本已生成随机值；禁止示例配置上线；发现默认值立即轮换 |
| R-4 | 升级回滚、真机渗透未在本环境执行 | 交付环境按 §4-5/4-6 演练并归档输出 |
| R-5 | 日志季度分区需运维预建 | 纳入季度运维任务 |

部署级红线（非 root、端口收敛、离线完整性、升级回滚）已完成静态核查与脚本级验证，**真机证据待补**，不得对外宣称已通过。
